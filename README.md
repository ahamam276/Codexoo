# Trend Dash

Trend Dash is a lightweight static web arcade game designed around visitor-friendly growth loops:

- a daily seeded challenge so everyone competes on the same run,
- a 60-second session length for quick replays,
- one-tap native sharing with clipboard fallback,
- responsive keyboard, mouse, and touch controls,
- SEO/social metadata for rich previews.

Open `index.html` in a browser or serve the folder with any static host.
